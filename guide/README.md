# PM-Agent 阅读指南

`guide/` 集中提供面向仓库读者的专题说明。根目录 README 提供整体视图，本目录按主题展开系统设计与运行方式。

## 阅读路径

### 第一次了解项目

1. 从[根目录 README](../README.md)了解项目定位、核心能力和完整链路。
2. 阅读[系统架构](系统架构.md)，理解 Vue 3、FastAPI、MySQL、Redis、MinIO 与 LLM 的职责边界。
3. 阅读[资料与上下文](资料与上下文.md)，理解文件如何转化为可追溯知识资产。
4. 阅读[Agent 与多维分析](Agent与多维分析.md)，理解复合问题如何拆解、召回和回答。

### 准备本地运行

直接阅读[运行与验证](运行与验证.md)，完成中间件、后端和前端启动，再按照验证清单检查服务状态。

### 关注 Agent 与 RAG 设计

建议按以下顺序阅读：

```text
资料与上下文：知识资产和来源有效性
  → Agent 与多维分析：请求计划和工具调用
  → 系统架构：服务边界与数据职责
  → 运行与验证：测试口径和当前限制
```

## 当前实现范围

当前公开说明以仓库中的实际运行代码为准：

- 后端为 **FastAPI 模块化单体**，不存在 Java 业务运行时或 Java/Python 业务自调用。
- 在线业务依赖为 **MySQL、Redis、MinIO 与 LLM**。
- 当前生产召回为可解释的词法分层召回，**不依赖向量数据库**。
- 持久化项目会话当前返回 JSON；SSE 事件编排已经存在于服务层，但尚未接入该公开接口。
- 任务状态机和风险处置流程尚未开放，Agent 当前只提供分析、草案和报告。

这些边界用于区分“当前可运行能力”和“后续演进方向”，避免把设计预留写成已经交付的功能。
