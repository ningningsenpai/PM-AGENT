# 技术选型

## 1. 架构结论

PM-Agent 使用 Python 模块化单体承载在线业务与 Agent 编排：

```text
Vue 3
  ↓ HTTP / SSE
FastAPI
  ├── auth / user / project / project_file
  ├── agents / llm / memory / normalization / project/context / rag
  └── core / infrastructure
       ↓
MySQL / Redis / MinIO / LLM
```

不保留 Java 运行时，不存在 Java 与 Python 双写或业务 HTTP 自调用。

## 2. 前端

| 能力 | 选型 |
|---|---|
| 框架 | Vue 3 + TypeScript + Vite |
| 状态管理 | Pinia |
| 路由 | Vue Router |
| UI | Naive UI |
| HTTP | Axios，统一注入 Bearer Token 与 `X-Trace-Id` |

## 3. Python 后端

| 能力 | 选型 |
|---|---|
| Web | FastAPI |
| 数据校验 | Pydantic v2 |
| ORM | SQLAlchemy 2.0 异步 ORM |
| MySQL 驱动 | asyncmy |
| 数据库迁移 | Alembic |
| JWT | PyJWT |
| 密码哈希 | pwdlib + Argon2 |
| 会话与幂等 | Redis |
| 对象存储 | MinIO Python SDK |
| LLM | 既有统一模型适配器 |

运行基线为 Python 3.11 及以上。

## 4. 数据与基础设施

- MySQL 是业务事实源，只有 Python Repository 可以访问业务表。
- Alembic 是唯一 Schema 所有者，不保留 Flyway。
- Redis 保存 JWT `jti` 登录会话和两分钟幂等门禁。
- MinIO 保存项目文件、文件详情和可重建索引快照。
- LLM 不获得数据库 Session，也不能返回待直接执行的 SQL。
- RabbitMQ 不接入当前链路。
- Qdrant 仅通过 `rag` Compose Profile 用于独立实验，不是在线启动依赖。

## 5. 模块化单体规则

业务模块位于 `agent-service/app/modules/<module>/`，每个模块独立包含 API、Schema、Domain、Model、Repository、Service 和 Errors。

- API 只处理协议和依赖注入。
- Service 负责事务边界与业务编排。
- Repository 只执行本模块持久化。
- ORM 模型不作为 HTTP 响应直接返回。
- 外部 MinIO、Redis、LLM 调用不放在数据库事务内。
- 跨模块只调用公开 Service，不跨表操作。
- Agent 工具只能调用模块 Service。
