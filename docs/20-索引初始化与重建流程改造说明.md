# 索引初始化与重建流程改造说明

## 改造结果

项目索引已经从 Java/Python 往返链路收敛为 Python 进程内编排。

```text
前端上传文件
  ↓
Python 先落库、事务外写 MinIO
  ↓
前端调用 /files/parse/init
  ↓
Python 读取对象、解析、调用模型
  ↓
Pydantic 校验
  ↓
写 file_details、更新数据库投影
  ↓
从数据库完整生成 index.json
```

已删除的旧链路：

- Java 组装文件分析 DTO；
- Java 生成临时 URL；
- Python 通过 HTTP 下载；
- Python 同步返回 Java；
- Java 回填数据库；
- Java 下载旧索引后读改写。

## 验收要点

- 不存在 `/api/v1/project-files/analyze`；
- MinIO 与 LLM 调用不处于数据库事务中；
- `index.json` 可从 MySQL 重新生成；
- 文件内容变化时，旧分析结果无法通过条件更新覆盖新版本；
- `eval`、`training` 等受保护目录不受影响。
