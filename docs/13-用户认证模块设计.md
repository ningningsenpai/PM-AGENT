# 用户认证模块设计

## 1. 范围

当前认证模块支持多用户邮箱注册、登录、注销、资料更新和密码修改，不包含租户、组织、角色或完整 RBAC。

邮箱是登录标识，用户名用于展示。注册和登录请求均为 JSON。

## 2. 安全基线

- 密码使用 `pwdlib[argon2]` 哈希，不保存或记录明文。
- JWT 使用 PyJWT 签发，包含 `sub`、`jti`、`iat`、`exp`。
- Redis 保存 `jti → user_id` 登录会话，TTL 与 JWT 一致。
- 注销直接删除 Redis 会话。
- 用户禁用后不得创建新会话；已签发会话可由管理流程统一撤销。
- JWT 密钥必须通过环境变量注入，生产环境不得使用示例值。

## 3. 模块结构

```text
app/modules/
├── auth/
│   ├── api.py
│   ├── schemas.py
│   ├── repository.py
│   └── service.py
└── user/
    ├── api.py
    ├── schemas.py
    ├── models.py
    ├── repository.py
    └── service.py
```

`auth` 负责会话编排，`user` 负责用户事实与密码校验。API 不直接访问 MySQL 或 Redis。

## 4. 接口

- `POST /api/v1/auth/register`
- `POST /api/v1/auth/login`
- `POST /api/v1/auth/logout`
- `GET /api/v1/users/me`
- `PUT /api/v1/users/me`
- `PUT /api/v1/users/me/password`

登录成功返回 `tokenName=Authorization`、`tokenValue` 和安全用户资料。受保护接口接受 `Authorization: Bearer <token>`。
