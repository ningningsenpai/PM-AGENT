# 云端上下文与显式学习改造

## 已确认范围

首轮完善显式学习，隐式学习后置。在 `main` 分阶段开发、验证并以中文提交到本地和远端。

- MinIO 保存正式上下文、待确认草稿、反馈轮次、来源和历史版本。
- MySQL 保留身份权限、会话消息、运行、处理游标和对象引用，不再作为有效上下文正文的召回来源。
- 后端使用有限容量内存缓存；版本清单按请求读取，正文按用户、项目、对象版本缓存。Redis 内容缓存后置。
- 学习流程为提取、预览、定向反馈、重新整理、确认、发布；所有草稿均不参与正式召回。
- 分类包括用户习惯、项目规范、术语词库、短期记忆和长期记忆。人工结构化编辑不调用模型，自然语言整理才调用模型。

## 发布边界

用户通用范围位于 `PM-AGENT/user_context/{userId}/context/`，项目范围位于 `PM-AGENT/{userId}/{projectId}/system/context/`。每个范围使用 `manifest.json` 指向不可变版本目录中的分类文件和变更记录。

先写完整分类文件，再通过读取时取得的 ETag 条件更新版本清单。只有清单更新成功才生效。条件失败不能无条件覆盖；超时后根据操作标识遍历已提交版本链恢复结果。跨作用域分别发布并返回部分成功状态。

条件发布使用 S3 的 `If-Match`／`If-None-Match` 协议，参考 [MinIO 官方说明](https://www.min.io/blog/leading-the-way-minios-conditional-write-feature-for-modern-data-workloads)。Python SDK 7.2 的条件头适配集中在 `ObjectStorage`，上线前必须执行当前服务的条件写入探针。

## 阶段与验收

1. 内容契约与条件发布：验证范围隔离、并发冲突、部分写入不生效、超时恢复和版本缓存。
2. 云端内容与显式学习：迁移旧内容，停止数据库正文双写；草稿和反馈可恢复，确认与具体版本绑定，规则与记忆统一召回。
3. 前端结果与分类管理：对话内结果卡、定向反馈抽屉、直接编辑、分类筛选、历史与来源。
4. 联调与收尾：完整后端测试、前端契约／类型／构建检查、浏览器验收及文档同步。

迁移保留已有来源、状态、期限和历史，禁止以空文件覆盖已存在云端版本。新旧表暂不删除，旧正文仅供迁移与历史核对；不改写既有 Alembic revision。

## 第一阶段验证

2026-09-08，后端 339 项单元测试通过。新增验证包括分类文件写入失败不生效、并发发布仅一方成功、旧基础版本拒绝、写入成功但响应丢失时恢复，以及后续版本发布后仍能识别旧幂等操作。

当前配置的真实 MinIO 已通过首次创建、重复创建拒绝、错误 ETag 拒绝及正确 ETag 更新探针；独立探针对象已清理。未修改项目对象、未执行数据库迁移、未调用真实模型。本阶段仅加入存储基础，现有学习接口在第二阶段切换。


## 第二阶段实现

正式内容读取已切换到 ContextStore；缺少新版清单时执行一次性导入，旧 MySQL 表和固定云端文件保留核对。迁移完整保留旧 SQL 变更记录，并将旧云端文档原样归档。不要在旧 `short_term_memory.json`、`user_habits/*.json` 或 `learned_context/v*.json` 中寻找新学习结果；请从 `context/manifest.json` 跟随当前分类引用。旧 publish 接口仅用于兼容查询，不会重建正文。

学习草稿保存于项目 `context/drafts/{draftId}/manifest.json`，指向不可变 revisions 文件。草稿保存候选、精确原文、基础版本、反馈和前后候选历史。学习游标仅表示已提取；MinIO 草稿已落盘而数据库完成记录失败时，可从草稿恢复，下一次学习不会重复提取已落盘消息。

确认先把具体版本和选择保存成不可变发布计划，再分别发布个人/项目范围。写入成功但响应丢失可按操作 ID 恢复；部分失败只重试失败范围；基础版本变化后提供重新核对入口。已成功范围不能通过重新整理再次应用。待确认草稿、反馈及历史不是缓存，服务重启后仍可读取。

文件解析规范由公开 ContextService 与学习共用项目清单，规范原始聚合文件也纳入该清单。文件刷新保留人工改过的条目，差异写入历史供核对。现有模型工具仍只读；显式学习接口是本轮受控的模型提案入口，没有任意路径文件写工具，也没有隐式学习。

后端初轮 344 项单元测试通过，包含迁移后禁止 SQL 正文召回、人工纠正幂等、跨范围部分发布、反馈隔离、同条件冲突、规范与人工纠正并发版本检查。本轮未改数据库结构，无需新增 Alembic 迁移；未调用真实模型。
