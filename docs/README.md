## 文档使用约定

- 所有文档必须由 Markdown 编写；
- 正式文档命名使用 `序号-中文标题.md`；
- 重大设计变更必须更新对应文档；
- 文档不写历史代码细节，只写设计目标、方案、规则、验收标准；
- 每个正式文档最后保留“待确认问题”章节，便于后续补充；
- 新增业务概念必须先更新 [00-术语表.md](./00-术语表.md)，再进入数据建模、接口设计和代码实现。
