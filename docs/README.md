## 文档使用约定

- 所有文档使用中文 Markdown。
- 长期文档命名优先使用 `序号-中文标题.md`，模块和专题文档使用语义化中文名称。
- 文档清理后编号不强制连续，不为了补号大规模重命名历史文档。
- 重大设计变更必须同步更新对应文档，避免出现多处描述同一规则。
- 文档不写历史代码细节，只写当前设计目标、规则与验收标准。
- 新增业务概念必须先更新 [00-术语表.md](./00-术语表.md)，再进入数据建模、接口设计和代码实现。
- 每个文档可保留「待确认问题」章节，没有未决问题时写「暂无」即可。
