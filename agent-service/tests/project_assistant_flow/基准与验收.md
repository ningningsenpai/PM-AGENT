## 七部分验收

1. 环境与恢复：三项中间件实际读写、Alembic 到 head、服务无 reload、重启后会话/条目/报告/轨迹可读。
2. 文件：创建项目，plan，upload，修改/删除测试样本副本后再次 plan/update，再 parse，查看失败和定向重试。
3. 会话：服务端历史连续；相同键同内容不重复生成，不同内容冲突；其他用户无法读消息或轨迹。
4. 工具：每轮必须真实成功调用八个目标工具。目录和执行实现一致；参数、未知工具、越权、超时、无数据及次数耗尽由确定性测试验证。
5. 学习：显式 learn 才写入；词条与习惯用户内复用，项目决策隔离；纠正保留版本和原话；失效与过期不再召回；重复 learn 无新增。
6. 报告：开发及风险报告保存后可读取；生成时间和来源版本可查；每个证据 ID 都可关联本轮实际原文范围。
7. 闭环：纠正后再次提问使用新值，同时说明旧文档未修改；断点续跑沿用状态但不覆盖已存在记录。

## 连续通过规则

相同源码、配置和 Prompt 连续三轮全部通过。源代码或 Prompt 改动后重新计数；失败轮和调优记录永久保留。HTTP 200、脚本退出码和模型直接答对都不能替代工具覆盖或事实验收。

费用使用真实 usage 按 Flash 高峰未命中输入 3 元/百万、输出 9 元/百万保守记账；未知 usage 保留调用前预留，累计最多 30 元。估算不是服务商账单。[官方价格说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)
