# v3 工程加固迭代记录

## 版本结论

v3 将样本完成度从 70% 提升到 80%。本轮关闭任意来源跨域风险，并给新增、编辑接口增加 Demo 级幂等保护；登录鉴权、权限和审计仍未完成，所以阶段三不能标记为全部完成。

## 已完成变更

- CORS 从 `allowedOriginPatterns("*")` 改为仅信任 `http://localhost:15173`，R-04 已关闭。
- `POST /api/v1/students` 与 `PUT /api/v1/students/{id}` 都要求 `X-Idempotency-Key`。
- 相同幂等键在 10 分钟保留期内只能登记一次，重复提交会返回中文错误。

## 设计限制

当前 `IdempotencyRegistry` 使用单进程内存和 `ConcurrentHashMap`，仅适合 Demo。生产部署必须迁移到带过期时间的共享存储，并保存请求摘要与首次响应；本轮不能据此宣称已经具备分布式幂等。

## 仍未完成事项

- 教师登录、角色权限、操作审计、敏感字段脱敏和明文凭据迁移仍未实现。
- 逻辑删除、分页、班级、课程、成绩与 React 编辑表单仍未实现。
- 没有生产环境用户量、CPU/内存容量、SLA 或法定数据保留期限的事实数据。
