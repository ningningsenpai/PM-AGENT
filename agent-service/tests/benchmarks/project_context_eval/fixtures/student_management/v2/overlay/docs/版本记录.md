# v2 档案维护迭代记录

## 版本结论

v2 将样本完成度从 50% 提升到 70%。学生编辑的 Controller、Service、Repository 和前端 API 封装已经完成，但 React 编辑表单尚未接入，因此不能宣称编辑功能已经完成端到端验收。

## 已完成变更

- 姓名模糊查询由字符串拼接改成 `LIKE ?` 参数绑定，R-03 已关闭。
- 新增 `PUT /api/v1/students/{id}`，可更新姓名、性别、年级、电话、邮箱和状态。
- 学号和创建时间不属于编辑请求，不允许经该接口修改。
- Repository 的更新语句仍然检查 `deleted = 0`，更新不存在或已删除记录时返回“学生不存在”。

## 未完成事项

- 逻辑删除、分页、班级、课程和成绩仍未开发。
- 新增和编辑接口仍未接入鉴权、权限、审计和幂等控制，R-05 保持打开。
- React 编辑表单和前端交互自动化测试尚未完成，R-07 保持打开。

## 验证记录

后端新增了编辑链路实现，但本版本冻结时仅完成代码审查和后端测试设计，尚未记录独立性能压测数据。
