## 下一轮改进优先级

1. 为工具循环增加查询去重、证据饱和度和保底作答策略；达到工具上限前必须基于已有最佳证据生成回答。
2. 增加上下文预算规划：按文件与证据类型设置配额，合并重复证据，优先保留人工可引用原文，超限前进行确定性压缩。
3. 把可回答性判断与最终生成分开校准，使用召回覆盖、Top-K 分差、原文证据类型和矛盾信号，降低可回答题的误拒答。
4. 建立结构化引用契约：回答先输出结论与 `path/startLine/endLine`，再由确定性校验器验证路径、行号和声明支持关系，不通过则降级或重写。
5. 针对跨文件题做查询分解与覆盖感知召回，要求不同子问题至少各有一条证据后再进入重排。
6. 修复后复跑同一冻结集；只有首轮 50 题门禁通过，再运行多随机种子 A4，并报告均值、标准差和失败率。

## 口径限制

- 当前只有一个小型学生管理项目及其三个历史版本，结论用于验证方法和定位系统缺陷，不代表跨语言、跨规模项目的泛化水平。
- 回答质量包含模型裁判，虽使用严格 Schema、冻结要点和引用路径确定性提取，仍应对边界样本做人工抽审。
- A0～A3 是文件级检索评测；真实 Agent 还包含请求规划、工具循环、上下文拼装和生成，因此不能用离线检索指标替代端到端结果。
