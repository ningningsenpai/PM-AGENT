# 简易学生管理系统接口文档

## 1. 通用约定

- 基础地址：`http://localhost:18080`
- 业务前缀：`/api/v1`
- 内容类型：`application/json`
- 当前阶段无鉴权，属于待识别问题。

统一响应：

```json
{
  "code": 0,
  "message": "成功",
  "data": {},
  "traceId": "d98f2f63e4554ec2b75d219ec09c7414"
}
```

## 2. 阶段一接口（已实现）

### 2.1 查询学生列表

- 方法：`GET`
- 路径：`/api/v1/students`
- 权限：当前无

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| name | query | string | 否 | 姓名模糊查询；当前实现故意存在 SQL 拼接问题 |

响应 `data` 为学生数组，字段如下：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | long | 自增业务 ID |
| studentNo | string | 学号 |
| name | string | 姓名 |
| gender | string | 性别代码：MALE/FEMALE |
| grade | string | 年级 |
| phone | string | 电话，当前未脱敏 |
| email | string | 邮箱，当前未脱敏 |
| status | string | ACTIVE/INACTIVE |
| createdAt | datetime | 创建时间 |

### 2.2 查询学生详情

- 方法：`GET`
- 路径：`/api/v1/students/{id}`
- 权限：当前无

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| id | path | long | 是 | 学生自增 ID |

不存在时返回：

```json
{"code": 20001, "message": "学生不存在", "data": null, "traceId": "..."}
```

### 2.3 新增学生

- 方法：`POST`
- 路径：`/api/v1/students`
- 权限：当前无
- 幂等键：当前未实现

请求体：

```json
{
  "studentNo": "20260004",
  "name": "陈晨",
  "gender": "FEMALE",
  "grade": "2026级",
  "phone": "13800000004",
  "email": "chenchen@example.test"
}
```

| 字段 | 类型 | 必填 | 校验 |
|---|---|---|---|
| studentNo | string | 是 | 4～20 字符 |
| name | string | 是 | 2～30 字符 |
| gender | string | 是 | MALE/FEMALE |
| grade | string | 是 | 最长 20 字符 |
| phone | string | 否 | 最长 20 字符 |
| email | string | 否 | 邮箱格式、最长 100 字符 |

成功后 `data` 返回新学生完整信息；学号重复返回 `20002`。

## 3. 阶段二接口（仅设计，未实现）

| 方法 | 路径 | 说明 | 主要参数 |
|---|---|---|---|
| PUT | `/api/v1/students/{id}` | 编辑学生 | name、gender、grade、phone、email、status |
| DELETE | `/api/v1/students/{id}` | 逻辑删除学生 | id、X-Idempotency-Key |
| GET | `/api/v1/classes` | 班级列表 | grade、page、size |
| POST | `/api/v1/classes` | 新增班级 | className、grade、headTeacher |
| GET | `/api/v1/courses` | 课程列表 | keyword、term |
| POST | `/api/v1/courses` | 新增课程 | courseCode、courseName、credit |
| GET | `/api/v1/students/{id}/scores` | 学生成绩 | term |
| POST | `/api/v1/students/{id}/scores` | 录入成绩 | courseId、term、score、X-Idempotency-Key |

阶段二所有写接口计划要求 `X-Idempotency-Key`，并返回统一错误码。

## 5. 错误码

| 错误码 | 中文消息 | 阶段 |
|---:|---|---|
| 0 | 成功 | 一 |
| 10001 | 请求参数不合法 | 一 |
| 20001 | 学生不存在 | 一 |
| 20002 | 学号已存在 | 一 |
| 90000 | 系统繁忙，请稍后重试 | 一 |
| 10002 | 缺少幂等键 | 二 |
| 30001 | 未登录 | 三 |
| 30002 | 无权执行该操作 | 三 |
