# Agent 服务设计文档索引

本目录用于集中保存 Agent 服务在产品定位、上下文资产、分析流程、模型编排和后续专题问题上的正式设计文档。

目录内文档用于约束后续设计与实现，不作为运行时数据目录，也不保存模型生成产物、测试样本或临时排查日志。

## 文档索引

| 文档 | 状态 | 用途 |
|---|---|---|
| [01-项目上下文资产职责与协作设计.md](./01-项目上下文资产职责与协作设计.md) | 设计已确认，待实施 | 明确原文件、索引、文件详情、项目规则、用户习惯、长短期记忆和对话记录的职责、来源、更新方式及协作边界 |

## 维护约定

1. 一个专题问题对应一份独立 Markdown 文档，不把无关设计堆叠到同一文件。
2. 文档描述当前确认的目标设计；未实现能力必须明确标记为“待实施”。
3. 后续设计如果推翻本目录已有结论，应直接更新对应文档并保留必要的变更说明，避免多份文件表达相互冲突的口径。
4. 涉及项目正式术语、业务实体、接口或数据库结构时，还需同步维护仓库根目录 `docs/` 下的对应长期规范文档。
5. 本目录不替代需求、任务、迭代、风险、报告和 Agent Trace 等正式业务数据。
